# 🤖 AI Engineering & LLM Systems

I’m currently building and experimenting with **AI/LLM systems focused on retrieval, reliability, confidence estimation and intelligent application workflows**.

### 🔗 Multi-Agent LLM System

Building a **4-agent LangGraph pipeline** consisting of:

```text
                ┌──────────────┐
                │   Retrieval  │
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │   Reasoning  │
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │ Verification │
                └──────┬───────┘
                       ↓
                ┌──────────────┐
                │    Answer    │
                └──────────────┘
```

The system explores how multiple specialized agents can work together to produce **more reliable and confidence-aware answers**.

### Current Work

* Building multi-agent workflows using **LangGraph**
* Implementing retrieval and reasoning pipelines
* Exploring **RAG architectures**
* Working with hybrid retrieval using:
  * BM25
  * Dense retrieval
  * Reciprocal Rank Fusion (RRF)
* Using vector databases for semantic search
* Evaluating model confidence using:
  * Expected Calibration Error (ECE)
  * Brier Score
* Experimenting with cross-agent consistency and verification
* Working with the **HotpotQA benchmark**
* Exploring groundedness and hallucination verification

### Technologies

`Python` · `LangChain` · `LangGraph` · `RAG` · `BM25` · `Dense Retrieval` · `RRF` · `ChromaDB` · `Google Gemini API` · `Vector Search`
